## `> whoami`

```bash
$ cat /dev/stampsynk
Nome:   StampSynk · estúdio de imagens
Foco:   editar · marcar · comprimir · converter
Saída:  JPG · PNG · WebP · ICO · GIF · BMP · PDF
Modo:   PWA instalável · processamento no navegador
Custo:  gratuito · sem anúncios
Idiomas: Português · English · Español
```

O **StampSynk** é um estúdio de imagens que funciona no navegador. Edite fotos, aplique marcas-d’água em lote, ajuste tamanhos e formatos, comprima arquivos e crie PDFs ou colagens. O projeto informa que o processamento é feito localmente no navegador.

---

## `> ls ./recursos`

| Ferramenta | O que você encontra |
| --- | --- |
| 🖼️ **Studio** | Ajustes de luz e cor, filtros, histograma RGB, corte, camadas e recorte de fundo; exportação em JPG, PNG ou WebP |
| 🔖 **Overlay e marca-d’água** | Aplique texto, assinatura, logotipo ou selo em várias fotos; ajuste posição, tamanho, opacidade e mesclagem e baixe o lote em ZIP |
| 📉 **Compress** | Comprima imagens em lote com limites de tamanho predefinidos; aceita JPG, PNG, WebP e HEIC |
| 🔄 **Convert** | Converta HEIC/HEIF, WebP, PNG, JPG, SVG, GIF e BMP para formatos de saída compatíveis, incluindo ICO em vários tamanhos |
| 📐 **Resize** | Redimensione imagens com tamanhos para redes sociais, vídeo, documentos e fotos de identificação, ou informe dimensões personalizadas |
| 📄 **PDF e Grid** | Reordene fotos para criar um PDF A4, Letter ou no tamanho original, ou monte colagens e grades |
| 🌐 **Idioma e aparência** | Alterne entre português, inglês e espanhol e escolha a aparência do estúdio |

## `> cat ./privacidade`

```json
{
  "processamento_de_imagem": "local no navegador",
  "upload_dos_arquivos": false,
  "modo_offline": true,
  "anuncios": false,
  "formatos_principais": ["JPG", "PNG", "WebP", "HEIC", "PDF"]
}
```

- **Processamento local:** segundo o site, as imagens são processadas no navegador, sem envio dos arquivos para servidores.

- **Uso offline:** o estúdio pode ser instalado como PWA e as ferramentas são apresentadas como disponíveis offline.

- **Sem anúncios:** o projeto se identifica como gratuito e sem anúncios.

- **Exportação no seu dispositivo:** escolha o formato e baixe o resultado após editar ou converter.

> [!NOTE]
O README descreve o processamento de arquivos informado pelo projeto. Recursos do navegador e a instalação inicial podem depender de suporte do dispositivo e de conexão.

## `> ./iniciar`

```bash
1. Acesse   stampsynk.github.io
2. Abra     uma foto no Studio ou selecione um dos módulos do menu
3. Edite    ajuste, marque, comprima, converta ou redimensione
4. Exporte  escolha o formato e salve o resultado
5. Instale  use "Install App" para adicionar o PWA ao dispositivo
```
